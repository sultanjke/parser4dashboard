# Парсер новостроек Казахстана: krisha.kz, korter.kz, kn.kz

Скрипт собирает жилые комплексы (новостройки) со сроком сдачи **с указанного года и позже** (по умолчанию с 2026)
с трёх крупнейших казахстанских сайтов недвижимости и сохраняет результат в Excel - отдельный файл на каждый сайт.

- **krisha.kz** - каталог ЖК (`/complex/`)
- **korter.kz** - новостройки по городам
- **kn.kz** - каталог жилых комплексов

## Установка

Нужен Python 3.10+.

```
git clone https://github.com/sultanjke/parser4dashboard.git
cd scraper
pip install -r requirements.txt
```

## Справочник

```
python -m scraper --help                       # все параметры
```

Результаты сохраняются в `output/`:

| Файл | Содержимое |
|---|---|
| `krisha_result_<дата>.xlsx` | одна строка на **очередь** ЖК (только очереди со сроком ≥ года) |
| `korter_result_<дата>.xlsx` | одна строка на **очередь** ЖК |
| `kn_result_<дата>.xlsx` | одна строка на **ЖК** (срок сдачи - самый поздний из домов) |
| `scrape_<дата>.log` | подробный лог; ЖК, которые не удалось загрузить, перечислены в конце |

## Как отбираются ЖК

| Сайт | Отбор по году |
|---|---|
| krisha.kz | фильтр сайта «Год постройки» (`year[]`) + проверка срока каждой очереди. Зарубежные ЖК (Ташкент и т.п.) исключаются |
| korter.kz | все страницы ЖК из sitemap; по каждому ЖК проверяются сроки домов в каждой очереди. Списки сайта («новостройки-<город>-сдача-2026») не показывают полностью распроданные ЖК, даже строящиеся, - без sitemap терялась примерно четверть ЖК. Флаг `--fast` - только списки сайта |
| kn.kz | фильтра по году на сайте нет: просматриваются все страницы каталога, отбор по надписи «Сдача: 2027 год» / «Сдан в 2026 году» на карточке, затем по срокам домов на странице ЖК. ЖК без срока (обычно давно сданные) не выгружаются |
